==================================================
      საიდან იწერება პროგრამები?
==================================================

1. ბრძანება: pkg install python
   - გზა: Termux App -> Termux Mirror (საცავი).
   - პროვაიდერი ხედავს: კავშირს Mirror-თან.
   - შიგთავსი: Termux-ისთვის მორგებული Python.

2. ბრძანება: pip install [ბიბლიოთეკა]
   - გზა: Termux App -> PyPI.org.
   - პროვაიდერი ხედავს: კავშირს Python-ის გლობალურ
     ბაზასთან.

3. ბრძანება: git clone [მისამართი]
   - გზა: Termux App -> GitHub.com (ან სხვა).
   - პროვაიდერი ხედავს: კავშირს GitHub-თან.
