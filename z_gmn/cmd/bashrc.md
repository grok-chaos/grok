1. რა არის .bashrc? (Bash Run Commands)
   - ეს არის სკრიპტი, რომელიც ავტომატურად ეშვება
     ყოველ ჯერზე, როცა Termux-ს ხსნი.
   - მდებარეობა: ყოველთვის Home (~) საქაღალდეში.
   - ფაილის ტიპი: დამალული (იწყება წერტილით).

2. რატომ ვიყენებთ მას?
   - Alias-ების (ფსევდონიმების) შესაქმნელად.
   - გარემო ცვლადების (Variables) დასაყენებლად.
   - ტერმინალის ვიზუალის (Prompt) შესაცვლელად.
   - ავტომატური მისალმების დასაწერად.

3. ძირითადი ბრძანებები:
   - nano ~/.bashrc  -> ფაილის რედაქტირება.
   - source ~/.bashrc -> ცვლილებების მომენტალური
                         გააქტიურება.
   - ls -a           -> დამალული ფაილის დანახვა.

4. მაგალითები (რა ჩავწეროთ შიგნით):

   # ალიასები (Shortcuts)
   alias c="clear"
   alias install="pkg install"
   alias ..="cd .."
   
   # მისალმება
   echo "მოგესალმები, [შენი სახელი]!"
   
   # ინფორმაცია სისტემაზე
   date
   uptime
