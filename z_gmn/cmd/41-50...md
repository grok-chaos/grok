სიმბოლო ./ არ ნიშნავს ფაილის გაშვებას. სინამდვილეში:
​. (წერტილი) ნიშნავს "მიმდინარე საქაღალდეს".
​/ (დახრილი ხაზი) არის გამყოფი.
​ანუ, როცა წერ ./testi.sh, შენ ეუბნები სისტემას:
 "ამ საქაღალდეში ( . ) არსებული ( / ) ფაილი testi.sh
 აამუშავე".
​აი, მსგავსი "სიმბოლური" ბრძანებები, რომლებიც Linux-ში
 მუშაობისას ჰაერივით დაგჭირდება:
​🛠 Linux-ის მნიშვნელოვანი სიმბოლოები და "შორთქათები"

==================================================
   სიმბოლური ბრძანებები და მათი დანიშნულება
==================================================

1. . (წერტილი)
   - მნიშვნელობა: მიმდინარე ადგილი.
   - გამოყენება: cp /storage/test.txt .
   (დააკოპირე test.txt აქ, სადაც ახლა ვარ)

2. .. (ორი წერტილი)
   - მნიშვნელობა: ერთი საფეხურით ზემოთ (უკან).
   - გამოყენება: cd ..
   (გადი საქაღალდიდან უკან)

3. ~ (ტილდა)
   - მნიშვნელობა: შენი მთავარი (Home) საქაღალდე.
   - გამოყენება: cd ~
   (მიუხედავად იმისა, სად ხარ, მომენტალურად "სახლში" დაგაბრუნებს)

4. / (სლეში)
   - მნიშვნელობა: სისტემის საწყისი წერტილი (Root).
   - გამოყენება: cd /
   (მიგიყვანს იქ, საიდანაც მთელი სისტემა იწყება)

5. * (ვარსკვლავი/Wildcard)
   - მნიშვნელობა: "ყველაფერი".
   - გამოყენება: rm *.txt
   (წაშლის აბსოლუტურად ყველა .txt ფაილს)

6. && (ორმაგი ენდი)
   - მნიშვნელობა: ბრძანებების მიმდევრობა.
   - გამოყენება: pkg update && pkg upgrade
   (პირველი თუ წარმატებით დასრულდა, მერე დაიწყე მეორე)

7. # (ჰეშთეგი)
   - მნიშვნელობა: კომენტარი.
   - გამოყენება: # ეს კოდი წაშლის ფაილებს
   (სისტემა ამ ხაზს არ წაიკითხავს, მხოლოდ შენთვისაა)

8. ! (ძახილის ნიშანი)
   - მნიშვნელობა: ბოლო ბრძანების გამეორება.
   - გამოყენება: !!
   (გაიმეორებს იმას, რაც ბოლოს აკრიფე - კარგია თუ დაგავიწყდა 'sudo')

9. > და >> (გადამისამართება)
   - მნიშვნელობა: ფაილში ჩაწერა.
   - გამოყენება: echo "hi" > f.txt
   (ერთი ' > ' შლის ძველს, ორი ' >> ' ამატებს ბოლოში)

10. | (პაიპი/Pipe)
    - მნიშვნელობა: ბრძანებების გადაბმა.
    - გამოყენება: ls | grep "work"
    (პირველის შედეგი გადაეცი მეორეს დასამუშავებლად)

==================================================
