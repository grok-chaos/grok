==================================================
       NETWORK - ქსელური დიაგნოსტიკა
==================================================

1. ping [საიტი]
   - ამოწმებს, ცოცხალია თუ არა კავშირი.
   - ms (მილიწამი) გვიჩვენებს დაყოვნებას (Lag).

2. ip addr
   - გიჩვენებს შენი მოწყობილობის IP მისამართს.
   - ეძებე 'wlan0' სექციაში 'inet'.

3. nslookup [საიტი]
   - პოულობს საიტის ციფრულ (IP) მისამართს.
   - მაგ: google.com -> 142.250.185.78

4. tracepath [საიტი]
   - გიჩვენებს გზას შენი ტელეფონიდან საიტამდე.
   - დაინახავ, რამდენი სხვადასხვა სერვერი
     (ჰოპი) გაიარა სიგნალმა.
